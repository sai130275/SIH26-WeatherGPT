# WeatherGPT — Feature Implementation Matrix

> **Verification Standard**: Every entry in this matrix is strictly verified against active repository code. Features marked **Current MVP** exist and can be demonstrated today. Features marked **Future Expansion** represent planned architectural capabilities and are **not** present as running features.

---

## 1. Currently Implemented Features (Current MVP)

| Feature | Status | Current Implementation | Future Expansion |
| :--- | :---: | :--- | :--- |
| **Weather Dashboard** | **Current MVP** | [`DashboardPage.tsx`](../group1/src/pages/DashboardPage.tsx) renders live atmospheric metrics: temperature, feels-like, humidity, rain probability, wind speed, surface pressure, UV index, visibility, CAPE, and lightning detection flags. | Integration with localized micro-climate indices and block-level topographical contour displays. |
| **Forecast Engine** | **Current MVP** | [`weatherController.js`](../group2/src/controllers/weatherController.js) and [`DashboardPage.tsx`](../group1/src/pages/DashboardPage.tsx) deliver a 12-hour hourly timeline and a 7-day model consensus outlook. | Multi-NWP ensemble probability distributions and decadal historical trend comparisons. |
| **Active Alerts & Detail Modal** | **Current MVP** | [`AlertsPage.tsx`](../group1/src/pages/AlertsPage.tsx) and [`alertController.js`](../group2/src/controllers/alertController.js) provide geofenced alerts categorized by severity (Red/Orange/Yellow) with an interactive safety action modal. | National Common Alerting Protocol (CAP) automated ingestion and push broadcast dispatch. |
| **"Ask AI" Conversational Assistant** | **Current MVP** | [`AskAIPage.tsx`](../group1/src/pages/AskAIPage.tsx), [`chatController.js`](../group2/src/controllers/chatController.js), and [`llm_service.py`](../group3/app/services/llm_service.py) provide grounded natural language queries with intent and source badges. | Hybrid vector search against disaster standard operating procedures and ICAR crop contingency handbooks. |
| **Open-Meteo Integration** | **Current MVP** | [`OpenMeteoProvider.js`](../group2/src/providers/OpenMeteoProvider.js) fetches numerical forecasts synthesized from IMD, ECMWF, and GFS/NOAA without requiring API keys. | Additional multi-provider adapters (Tomorrow.io, MeteoBlue, IMD radar feeds, ISRO INSAT imagery). |
| **Node.js Orchestration Gateway** | **Current MVP** | [`group2/src/app.js`](../group2/src/app.js) orchestrates incoming client traffic, enforces rate limiting, normalizes CORS headers, handles JWT authentication, and proxies queries. | Edge distribution, API micro-caching across regional points of presence, and automated gateway clustering. |
| **FastAPI Intelligence Service** | **Current MVP** | [`group3/app/main.py`](../group3/app/main.py) provides high-performance Python microservices running Pydantic validation, condition detection, and mathematical risk evaluation. | Horizontal pod autoscaling, GPU-accelerated local inference endpoints, and automated model distillation. |
| **AI & Deterministic Fallback Behavior** | **Current MVP** | [`llm_service.py`](../group3/app/services/llm_service.py) automatically activates `FallbackProvider` (`mode: "fallback"`) when LLM keys are omitted or endpoints time out, outputting rule-based advice. | Dynamic local SLM (Small Language Model) inference running in-cluster during total internet blackouts. |
| **Global Unit Preferences** | **Current MVP** | [`PreferencesContext.tsx`](../group1/src/context/PreferencesContext.tsx) and [`units.ts`](../group1/src/utils/units.ts) synchronously propagate user unit selections (`°C`/`°F`, `km/h`/`mph`, `mm`/`in`, `hPa`/`inHg`) across all views. | Regional metric configurations and automatic locale-based unit presets. |
| **Voice-to-Text Input** | **Current MVP** | [`AskAIPage.tsx`](../group1/src/pages/AskAIPage.tsx) integrates the browser's native Web Speech API (`SpeechRecognition`) for hands-free speech input into the chat assistant. | Full server-side speech-to-text supporting dialectal Indian vernaculars via Bhashini API. |
| **Multi-Hazard Risk Engine** | **Current MVP** | [`risk_engine.py`](../group3/app/services/risk_engine.py) computes quantitative mathematical scores (0–100) and severity ratings across heat, flood, wind, and visibility. | Multi-factor vulnerability weighting incorporating historical drainage topography and census density. |
| **Sector Card Views** | **Current MVP** | [`MapPage.tsx`](../group1/src/pages/MapPage.tsx) renders structured domain cards for Farmer Advisory, Cyclone Tracker, Aviation, and Marine operations. | Dedicated domain micro-engines, radar track overlays, and specialized agronomic calculators. |
| **Database & Cache Fallbacks** | **Current MVP** | [`db.js`](../group2/src/config/db.js) and [`redis.js`](../group2/src/config/redis.js) provide automatic in-memory fallbacks when MongoDB or Redis are offline. | Resilient distributed cluster persistence with automated multi-region replication. |

## 2. Future Planned Features (Future Expansion)

| Feature | Status | Current Implementation | Future Expansion |
| :--- | :---: | :--- | :--- |
| **Toll-Free Voice Access** | **Future Expansion** | *Not Currently Implemented.* Browser Web Speech API exists for web users only. | Dedicated telephony/IVR gateway allowing callers to dial a toll-free number for spoken forecasts and advisories over basic feature phones. |
| **Advanced RAG** | **Future Expansion** | Structured telemetry grounding exists via [`evidence_engine.py`](../group3/app/services/evidence_engine.py). Document retrieval is *Not Currently Implemented.* | Vector database integration (pgvector/Qdrant) searching official ICAR crop advisories, government flood SOPs, and district relief protocols. |
| **Additional Weather Providers** | **Future Expansion** | Open-Meteo is currently the sole active provider in [`OpenMeteoProvider.js`](../group2/src/providers/OpenMeteoProvider.js). | Multi-provider ingestion (Tomorrow.io, MeteoBlue, IMD AWS radar feeds, ISRO satellite data) with automated consensus validation. |
| **Regional / Local Intelligence** | **Future Expansion** | Coordinate-based resolution exists. Local administrative intelligence is *Not Currently Implemented.* | Granular block- and panchayat-level micro-climate modeling combining topographical elevation, drainage contours, and local crop calendars. |
| **Expanded Farmer Advisory** | **Future Expansion** | Heuristic rainfall and pesticide spraying guidelines exist in active code. | Crop-specific phenology calculators (paddy, cotton, chilli, wheat), soil moisture sensor telemetry, and pest/fungal disease risk indices. |
| **Cyclone Intelligence** | **Future Expansion** | High-wind threshold evaluation exists in [`risk_engine.py`](../group3/app/services/risk_engine.py). | Tropical cyclone track cone visualization, barometric pressure drop velocity alerts, storm surge depth modeling, and landfall ETA projections. |
| **Aviation Intelligence** | **Future Expansion** | Aviation condition metrics card exists in [`MapPage.tsx`](../group1/src/pages/MapPage.tsx). | Automated METAR and TAF telegraphic report decoding, runway crosswind component calculators, and clear air turbulence (CAT) indices. |
| **Marine Intelligence** | **Future Expansion** | Coastal wind/visibility overview card exists in [`MapPage.tsx`](../group1/src/pages/MapPage.tsx). | Hydrodynamic wave model ingestion (significant wave height, swell period, sea surface temperature, and potential fishing zones). |
| **GIS & Map Intelligence** | **Future Expansion** | Interactive Leaflet map implementation preserved in [`archive/map/`](../archive/map/). Active view renders structured cards. | Re-integration of interactive Leaflet/MapLibre map with animated radar precipitation overlays, wind vector particles, and geofenced hazard polygons. |
| **Automated Notifications** | **Future Expansion** | Socket.IO server is active on the gateway; client-facing notifications are *Not Currently Implemented.* | Multi-channel automated alerts dispatched via SMS, WhatsApp, Web Push, and voice broadcasts based on user geofence preferences. |
| **Multilingual Support** | **Future Expansion** | Language selector (`en`, `te`, `hi`) and backend routing parameter exist; UI labels currently default to English. | Full localized UI string dictionaries for 12+ Indian regional languages and integration with the Bhashini Indian voice translation API. |
| **Mobile Application & PWA** | **Future Expansion** | Responsive web client optimized for mobile browsers exists. Installable PWA is *Not Currently Implemented.* | Progressive Web App manifest, Service Worker offline asset caching, background query synchronization, and native mobile builds. |
| **Scalable Infrastructure** | **Future Expansion** | Dockerfile provided for Group 2; cloud deployment on Render/Railway. | Kubernetes (Helm) manifests, horizontal pod autoscaling (HPA) for GPU/CPU inference, and multi-region Redis cluster. |
| **Analytics & Reporting** | **Future Expansion** | Basic console logging and health probes exist. Query analytics are *Not Currently Implemented.* | Administrative dashboards for regional hazard frequency heatmaps, query volume trends, alert delivery reach, and AI accuracy metrics. |
| **Government & Emergency Integration** | **Future Expansion** | Mock and local alerts exist in database models. | Direct ingestion of official NDMA and state disaster authority warnings via the Common Alerting Protocol (CAP). |
| **Community / Field Reports** | **Future Expansion** | *Not Currently Implemented.* | Crowdsourced citizen science module allowing verified local volunteers and agricultural officers to submit ground-truth disaster observations. |
| **IoT Sensor Integration** | **Future Expansion** | *Not Currently Implemented.* All telemetry is currently derived from NWP models. | Real-time MQTT/CoAP telemetry ingestion from low-cost automated weather stations (AWS), agricultural soil moisture probes, and rain gauges. |
